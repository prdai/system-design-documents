# tribal-knowledge-mcp

the idea of making tribal knowledge queryable by ai coding agents through an mcp server- so the context behind engineering decisions surfaces where and when it actually matters, instead of rotting in a wiki.

this is a conceptual + learning project. c++ for the server, faiss for the vectors, docker for deployment.
