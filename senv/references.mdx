# references

things that are relevant or will be useful while working through this design.

- [doppler](https://www.doppler.com) - commercial secret management, good reference for ux and feature set
- [hashicorp vault](https://www.vaultproject.io) - the heavyweight option- useful as a reference for what "full" looks like
- [cloudflare workers](https://developers.cloudflare.com/workers/) - runtime for the cf-native approach
- [cloudflare kv](https://developers.cloudflare.com/kv/) - storage for the cf-native approach
- [cloudflare access](https://developers.cloudflare.com/cloudflare-one/policies/access/) - auth layer for the cf-native approach
- [cloudflare d1](https://developers.cloudflare.com/d1/) - sqlite-based db for the cf-native approach
- [pgcrypto](https://www.postgresql.org/docs/current/pgcrypto.html) - postgres extension for column-level encryption, relevant for the docker approach
