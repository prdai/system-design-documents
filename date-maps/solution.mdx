# solution & requirements

a website protected behind cloudflare access that shows a map with clusters of dates and memories.

## the general idea

- built on next.js
- uses google maps, mapbox js, or whatever map library works best for this (not decided yet)
- shows a map of the world with clusters of dates/memories marked on it
- you can filter by day and see the flow of that day- where you went first, where you went next, the whole route
- protected behind cloudflare access so only the people you want can see it
