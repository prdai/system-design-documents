# date-maps

a cloudflare access protected website that visualizes dates and memories on a map- clusters of places you've been with someone, filterable by day with a flow view showing where you went and in what order.

built on next.js with a map (google maps or mapbox, tbd). originated from the idea of giving something meaningful to someone when you're better with code than with origami.

not just for couples- works for friend groups or anyone sharing experiences.
