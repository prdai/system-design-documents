# contributing to project

thank you for considering contributing to this project! i welcome contributions from the community.

## how to contribute

if there is any additioanl technical details or better alternatives that can be used, and a better approach to anything please feel free to put up a pr, and also if you build out the project it self, put up a pr with your github repository, so that people can see a implemented version of the design.

## code of conduct

this project adheres to a [code of conduct](code_of_conduct.md). by participating, you are expected to uphold this code.

thank you for contributing!
